# основные фичи

- от api получаем список пачек задач пользователя и отображаем на стринице задач
- аутентифицированному пользователю показываем только его ресурсы, чужие не показываем
- без аутентификации доступна только страница входа и главная (отдельная страница-визитка)

## пачки

- в списке отображаются в виде карточек
- у каждой крточки есть
    - заголовок
    - задачи
- можно добавлять новые пачки
- существующие можно удалять и редактировать, добавляя, удаляя или отмечая выполненными задачи внутри

## задачи

- каждая задача принадлежит одной пачке
- отображаются строчками
- отсортированы всегда одинаково внутри одной пачки (новые ниже)
- имеют:
    - заголовок
    - чекбокс выполненности
