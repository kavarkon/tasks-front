# страница входа 1


## контракт

- с любой страницы, кроме главной, unauthenticated user перенаправляется на страницу входа
- на странице входа 
    - форма для ввода email-адреса и пароля и кнопка для входа
    - кнопка на страницу регистрации
- после успешной аутентификации открывается страница задач
- если аутентификация не удалась, должно появиться какое-то сообщение


## реализация

- будет один файл sessions.js, который будет подключен на каждую страничку сайта
- все остальные страницы перед вызовом своей логики будут проверять, не нужно ли перенаправление
- будет формочка happy path, тогда мы перенаправляем пользователя на страницу задач
- ошибка "логин или пароль не верны"}

# страница регистрации

- на странице регистрации есть поля:
    - электронная почта
    - пароль
    - повторить пароль
- есть кнопка "зарегистрироваться"
- есть кнопка на страницу входа

- поля проверяют формат вводимых данных, в случае проблем поле будет подсвечиваться
    - почта валидная?
    - совпадение двух паролей

- при успешной регистрации происходит перенаправление на страницу входа
- если с сервера пришло сообщение о проблеме, сверху всей формы появится общее сообщение об ошибке, под полями появятся ошибки валидации
