# Пользователи

## Требования
* на странице /register пользователь может зарегестрироваться введя почту и пароль
* на странице /login пользователь может зайти введя почту и пароль
* после успешной регистрации пользователь перенаправляется на страницу входа
* после успешного входа открывается страница с задачами
* без активной сессии доступны только страницы входа и регистрации

## Пользовательские сценарии
### 1. пользователь успешно регистрируется
1. открыть /register
2. ввести person@example.com в поле email, secret в поле password и secret в поле confirmation
3. нажать register
4. проверить, что произошел переход на страницу /login

### 2. пользователь успешно входит
1. открыть /login
2. ввести person@example.com в поле email, secret в поле password
3. нажать login
4. проверить, что открылась страница /tasks

### 3. пользователь без сессии перенаправляется на страницу логина
1. у пользователя нет активной сессии
2. открыть /tasks
3. проверить, что произошел переход на страницу /login

## Реализация
* используется тег form, мы подписываестся через js на его событие submit
* когда происходит submit, мы вызываем функцию login() на странице логина или register()
на странице регистрации
* значения из формы отправляются через fetch на бекенд
* в зависимости от статуса (201, 200) пользователь или редиректится на нужную страницу, или ему показывается ошибка
